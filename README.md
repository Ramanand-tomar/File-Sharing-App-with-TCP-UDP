# 📡 Sharing App TCP

A high-performance, Peer-to-Peer (P2P) file sharing application built with **React Native**. This app leverages **TCP Sockets** for reliable, high-speed data transfer across local networks without relying on cloud servers or internet connectivity.

---

## ⚡ Key Features

- **🚀 High-Speed TCP Transfer:** Direct device-to-device communication using `react-native-tcp-socket`.
- **🔍 Auto Device Discovery:** Uses UDP broadcasting to find other devices on the same network automatically.
- **📱 QR Code Pairing:** Quick connection setup via QR code scanning for seamless "Sender-Receiver" handshakes.
- **📂 Multi-File Support:** Send images, documents, and large files with real-time progress tracking.
- **🛡️ Secure & Private:** Files are transferred directly between devices; no data is ever uploaded to the cloud.
- **🎨 Premium UI/UX:** Modern, glassmorphism-inspired design with smooth animations powered by Lottie and Reanimated.

## 🏗️ Architecture Overview

The app follows a service-oriented architecture to separate networking logic from the UI.

### 🔌 Core Services (`src/services/`)
- **`TCPProvider.tsx`:** The central hub managing the Socket жизненный cycle. It handles server initialization, client connections, and global transfer states.
- **`TCPUtils.tsx`:** Contains helper logic for chunking files, calculating checksums, and handling protocol-level handshakes.

### 📱 Main Screens (`src/screens/`)
- **`HomeScreen`:** The entry point to choose between "Send" and "Receive" modes.
- **`ConnectionScreen`:** Manages UDP discovery and QR scanning to establish a link.
- **`SendScreen`:** File picker integration and outgoing stream management.
- **`ReceiveScreen`:** Incoming stream listener and storage coordinator.
- **`ReceivedFileScreen`:** History and gallery view of transferred files.

## 🚀 Getting Started

### Prerequisites
- Node.js >= 20
- React Native Development Environment ([Setup Guide](https://reactnative.dev/docs/set-up-your-environment))

### Installation
1. Clone the repository:
   ```sh
   git clone https://github.com/your-repo/Sharing_App_TCP.git
   cd Sharing_App_TCP
   ```
2. Install dependencies:
   ```sh
   npm install
   # OR
   yarn install
   ```
3. (iOS only) Install pods:
   ```sh
   cd ios && pod install && cd ..
   ```

### Running the App
- **Android:** `npm run android`
- **iOS:** `npm run ios`

## 📖 How it Works (The Protocol)

1. **Discovery Phase:** The "Receiver" starts a UDP server and broadcasts its IP/Port. The "Sender" listens for these packets or scans a QR code generated by the receiver.
2. **Handshake Phase:** Once IPs are known, the Sender establishes a TCP connection. Both devices exchange device info and manifest data (filenames, sizes).
3. **Transfer Phase:** Files are read from the Sender's storage, converted to `Buffer` chunks, and streamed over the socket. The Receiver reconstructs these chunks and writes them to the local `Download` directory.
4. **Finalization:** A "Complete" signal is sent, and the connection is closed gracefully.
